AHC CORE / C++23 / HEADER-ONLY

「時間・乱数・状態」を、迷わず使う

AHCのコードに何度も出てくる3つの道具です。前提知識は不要です。必要なページを1つ選び、ヘッダをincludeしてください。

3つの道具組み合わせ方最小例README

何を使う？

制限時間

Timer

単調に進む時計で、残り時間と進み具合を確認します。

Timerを読む →
試行・shuffle

Rng

seedを明示して、同じ実験を同じ順番で再現します。

Rngを読む →
状態比較

Zobrist

特徴ごとの64bit値をXORし、状態をすばやく見分けます。

Zobristを読む →

AHCでの流れ

3つともオブジェクトが状態を持ちます。グローバル乱数やシステム時計に隠れて依存しません。

最小例

#include "core/timer.hpp"
#include "core/rng.hpp"

ahc::Timer timer(std::chrono::seconds(2));
ahc::Rng rng(1234);                 // seedを固定
while (!timer.expired()) {
  int action = rng.uniform_int(0, 4); // 0〜3。4は含まない
  (void)action;
}

詳しい境界、例外、テスト可能な時計は各ページへ。コンパイルにはC++23が必要です。
