AHC CORE / RNG

同じseedなら、同じ挑戦

ahc::Rng は速い64bit乱数です。seedを必ず受け取り、状態をオブジェクト内だけに持ちます。

core入口使うAPI境界

seedから値が出る

#include "core/rng.hpp"
#include <algorithm>
#include <vector>

ahc::Rng rng(42);
int i = rng.uniform_int(0, 10); // 0〜9
double x = rng.uniform_real(0.0, 1.0); // 0以上1未満
bool ok = rng.bernoulli(0.2); // trueの確率 0.2
std::shuffle(v.begin(), v.end(), rng);

`Rng` は標準のURBGです。`std::shuffle` に直接渡せます。

APIと区間

上端を含む？
API範囲・条件
uniform_int(low, high)[low, high)。整数。low < high。
uniform_real(low, high)[low, high)。有限な浮動小数。low < high。
bernoulli(p)p は [0, 1]。p=0は常にfalse、p=1は常にtrue。
unit()[0, 1) のdouble。
operator()()全ビットを使える uint64_t。seed列の基本単位。

同じseed・同じ呼び出し順なら同じ値です。別の標準ライブラリに依存する分布クラスを使わず、ここで区間と再現性を定めています。

境界と失敗例

失敗：uniform_int(0, 4) で4も出ると思う。実際は0,1,2,3だけです。4種類のActionならこの書き方が安全です。

失敗：範囲を逆にして自動修正を期待する。low >= high、非有限の実数、確率が0未満/1超は std::invalid_argument です。

try {
  rng.uniform_int(4, 0); // 例外。黙って交換しない
} catch (const std::invalid_argument&) {
  // 入力・定数のバグを直す
}

seedの扱い

本番で結果を再現したいなら、入力値や実験番号からseedを作って記録します。並列化する場合はスレッドごとに別の Rng を作ります。隠れた共有乱数はありません。

実行可能な確認は tests/rng_test.cpp にあります。
