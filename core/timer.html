AHC CORE / TIMER

締切まで、あと何秒？

ahc::Timer は steady_clock を使う制限時間タイマーです。時計をテスト用に差し替えることもできます。

core入口使うAPI境界

使い方

#include "core/timer.hpp"
#include <chrono>

ahc::Timer timer(std::chrono::seconds(2));
while (!timer.expired()) {
  // ここで候補を1つ試す
  double done = timer.progress(); // 0.0〜1.0
  (void)done;
}

`elapsed()` は経過時間、`remaining()` は残り時間です。単位は std::chrono の duration です。

API

主なメソッド
呼び出し意味
Timer(limit)今から測定開始。steady_clock。
elapsed()経過時間。制限時間を超えても増える。
remaining()残り時間。0未満にはならない。
progress()0.0〜1.0。締切後は1.0。
expired()期限に達したら true。
reset()今を新しい開始点にする。

elapsed_at(time_point)、remaining_at、progress_at、expired_at もあります。取得時刻を渡せるので、待たずにテストできます。

テスト用の時計

struct FakeClock {
  using duration = std::chrono::milliseconds;
  using time_point = std::chrono::time_point<FakeClock>;
  static time_point current;
  static time_point now() { return current; }
};
// ahc::BasicTimer<FakeClock> timer(1s, FakeClock::current);
// currentを進め、elapsed_at(current)を確認する。

実際の例は tests/timer_test.cpp にあります。

境界と失敗例

制限時間が0以下：0に正規化され、最初から expired()==true、progress()==1.0 です。

開始より前の時刻：テスト用の elapsed_at は0に張り付きます。残り時間は全量です。

失敗：std::chrono::system_clock の時刻を毎回読むと、OSの時刻補正で逆戻りすることがあります。締切判定には Timer を使います。

// よくある間違い：秒の整数に丸めてから比較
if (timer.elapsed().count() > 2) { /* 1秒台も混ざる */ }
// duration同士を比較する
if (timer.elapsed() >= std::chrono::seconds(2)) { /* 明確 */ }
