best_solution.hpp

マルチスタートで得た最良の State と score を一組だけ保持します。

最小 API

ahc::BestSolution<State> best(ahc::Objective::minimize);
if (best.consider(state, score)) { /* best が更新 */ }
if (!best.empty()) use(best.state(), best.score());

score の同値は更新しません。最初に入った状態を残します。空の state() / score() は std::logic_error です。
