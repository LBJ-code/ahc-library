annealing.hpp

温度と受理判定だけ。探索ループ、状態、近傍、タイマーは持ちません。

最小 API

std::mt19937_64 rng(seed);
ahc::LinearTemperature temp(20.0, 0.01);
double p = ahc::progress(elapsed_seconds, limit_seconds); // double
double delta = candidate_score - current_score;
bool ok = ahc::accept(ahc::Objective::minimize, delta, temp(p), rng);
// 同じ rng seed と同じ呼出順なら同じ結果。
  • LinearTemperature(start, end): 直線補間。温度は 0 以上。
  • ExponentialTemperature(start, end): log 空間補間。両端は 0 より大きい。
  • accept_minimize(delta, t, rng) / accept_maximize も利用可。
  • t が 0 以下・NaN は貪欲。大きな悪化量は exp せず対数比較。

失敗例

maximize でも delta = candidate - current。current - candidate にすると符号が逆です。

// NG: delta = current - candidate; maximize に渡す
// OK: delta = candidate - current; maximize に渡す
