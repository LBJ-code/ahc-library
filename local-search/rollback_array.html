rollback_array.hpp

候補を配列へ適用し、残すなら commit、捨てるなら rollback。

最小 API

ahc::RollbackArray<int> a{1, 2, 3};
auto mark = a.snapshot();
a[1] = 9;
if (keep) a.commit(mark); else a.rollback(mark);
  • checkpoint は入れ子にできる。
  • at は範囲外で std::out_of_range。
  • 不正な / 使用済み token は std::invalid_argument。
  • 非 const の配列アクセスは checkpoint ごとに差分を一度保存する。

snapshot 前に T& を保持し、その参照で後から書くと記録できません。変更時に a[i]、set、fill を呼び直してください。
