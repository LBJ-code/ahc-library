Timer・状態・近傍は問題側。ここには温度、受理、集計、差分復元だけがあります。

どれを使う？

annealing.hpp

progress、温度スケジュール、accept。乱数は引数で注入。

search_stats.hpp

attempts、accepted、improved、best、受理率。

rollback_array.hpp

候補を試して、rollback または commit。

best_solution.hpp

最良の状態と score を一組だけ保存。

最小ループ

const double p = timer.progress(); // core::Timer
auto move = make_neighbor(state, rng);
double candidate = evaluate_after(state, move);
double delta = candidate - score;
bool ok = ahc::accept(ahc::Objective::minimize, delta, temperature(p), rng);
if (ok) { apply(state, move); score = candidate; }
stats.observe(candidate, ok);

改善は常に受理。悪化だけが温度と乱数で決まります。最大化でも delta は同じ符号です。
