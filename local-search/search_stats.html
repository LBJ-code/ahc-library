search_stats.hpp

探索中の「どれだけ試し、どれだけ動き、best が何回更新されたか」を数えます。

最小 API

ahc::SearchStats<double> stats(ahc::Objective::minimize);
stats.seed(initial_score);
// 受理した候補だけを best と比較する
stats.observe(candidate_score, accepted);
std::uint64_t n = stats.attempts();
double rate = stats.acceptance_rate();
attempts()
試行数
accepted()
受理数
improved()
best 更新数
best()
best score

試行0回の受理率は 0.0。best 未登録で best() を呼ぶと logic_error、NaN の seed は invalid_argument です。
