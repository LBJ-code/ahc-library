grid.hpp — 点と近傍

Point{row, col}は盤面の1マスです。r/cとx/yも同じ順で使えます。

使い方

#include "utilities/grid.hpp"

ahc::Point p{2, 3};
if (ahc::inside(p, height, width)) {
    for (ahc::Point q : ahc::neighbors4(p, height, width)) {
        // 盤面内の q だけが来る
    }
}
long long d = ahc::manhattan_distance(p, ahc::Point{0, 0});

neighbors4(p)は上下左右の4点をそのまま返します。neighbors4(p,h,w)は盤面外を除いたvectorです。8方向版も同じです。

境界と計算量

insideは負の行・列、0以下の高さ・幅をfalseにします。近傍生成は最大8点なのでO(1)、距離もO(1)です。座標の比較はrow、次にcolの辞書順です。
