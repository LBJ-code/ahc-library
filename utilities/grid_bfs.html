grid_bfs.hpp — 盤面の最短経路

grid.hppのPointと4近傍を使い、壁を避ける距離・親・経路を一度に求めます。単一始点と複数始点に対応します。

使い方

#include "utilities/grid_bfs.hpp"

auto passable = [&](ahc::Point p) { return board[p.row][p.col] != '#'; };
auto result = ahc::bfs_grid(height, width, passable, ahc::Point{0, 0});
if (result.reachable(goal)) {
    auto path = result.path_to(goal); // 始点とgoalを含む
    int d = result.distance_to(goal);
}

std::vector<ahc::Point> starts{{0, 0}, {height - 1, width - 1}};
auto multi = ahc::bfs_grid(height, width, passable, starts);

距離はrow-majorのdistanceに保存され、未到達は-1です。parentは一歩手前のPoint、始点や未到達セルは{-1,-1}です。

境界契約

高さまたは幅が0以下なら空の結果を返し、passableは呼びません。正の盤面では述語を各セル1回だけ呼びます。範囲外・壁・重複した始点は無視し、到達不能なgoalの経路は空配列です。経路は4近傍の最短経路の一つです。
