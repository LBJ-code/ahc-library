weighted_sampler.hpp — 重みで1つ選ぶ

重みが大きい候補ほど選ばれます。内部のFenwick treeが累積和を持つので、更新も抽選もO(log n)です。

使い方

#include "utilities/weighted_sampler.hpp"

ahc::WeightedSampler sampler({1.0, 0.0, 3.0});
sampler.set(1, 2.0); // 候補1を更新（O(log n)）
std::mt19937_64 rng(seed);
auto index = sampler.sample(rng); // std::optional<size_t>
auto fixed = sampler.sample_with([] { return 0.25L; }); // 乱数注入

重みは有限の非負値だけです。総和0ならstd::nullopt、乱数0は最初の正の重み、乱数1は最後の正の重みを選びます。

計算量と更新

set/update/addと抽選はO(log n)。初期化とassignはO(n)です。標準URBGか、[0,1]を返すcallableを注入できます。
