permutation_ops.hpp — 列を少し変える

AHCの近傍解を、添字の事故なく作ります。変更に成功するとtrue、境界外ならfalseです。

使い方

#include "utilities/permutation_ops.hpp"

std::vector order{0, 1, 2, 3};
ahc::RelocateOperation op{1, 3}; // Bを最終添字3へ
if (op.apply(order)) {
    op.undo(order); // 元に戻す
}
ahc::reverse_segment(order, 1, 3); // [1, 3)だけ反転

swapは2つの有効な添字、reverseは[first,last)、relocateはfromと「移動後の最終to」を使います。すべて0始まりです。

計算量

swapはO(1)、reverseとrelocateは動かす要素数に比例します。逆操作はop.inverse()で得られ、Relocateなら{to, from}です。
